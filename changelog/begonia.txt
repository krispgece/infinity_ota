Project Infinity-X 3.12 | Android 16 | begonia | UNOFFICIAL
Build 25.09.2026 | Security patch 2026-09-01 | Kernel 4.14.357

This build switches to dynamic partitions and adds a Vanilla variant without Google apps.

Before you install:

• You need a recovery that supports dynamic partitions: Unified TWRP 3.7.1_12 by WuXing90 (link in the XDA thread). PBRP 4.1 and other static recoveries can't install this build. The installer stops at the start and nothing is changed.

• Coming from the 23 or 24 Sep build: flash that recovery in fastboot mode, boot to it and sideload this build. No Format Data is needed; apps and data are kept.

• Right after that first install, restart TWRP (Reboot > Recovery) before wiping or backing up anything in it.

• Switching between GApps and Vanilla needs Format Data.

Changes:

• Dynamic partitions: system, system_ext, product and vendor now live in super, built from the stock system and vendor partitions. The partition table doesn't change.

• New Vanilla variant without Google apps, with its own update feed.

• Data roaming is now off by default. On an update it is switched off too, unless you turned it on yourself.

• A vendor init script's attempt to create two Android 11 era folders is no longer logged as an SELinux denial.

Known issues:

• Video calling over the carrier network (ViLTE / ViWiFi) is not available. Video calls in apps such as WhatsApp work.

• Please report anything else you find, with a logcat if you can.
