Project Infinity-X 3.12 | Android 16 | begonia | UNOFFICIAL
Build 23.09.2026 | Security patch 2026-09-01 | Kernel 4.14.357

First public release for the Redmi Note 8 Pro.

What changed on the device side:

• SELinux is fully Enforcing from the very first instant of boot. The kernel command line no longer forces permissive mode, and the boot-time denial count is down from 88 to a handful of harmless ones.

• The kernel moved to the 4.14.357 OpenELA LTS branch, so it carries the current upstream security fixes.

• Per-app thermal profiles in XiaomiParts work for the first time. ThermalService is now declared, and the app runs in its own SELinux domain instead of borrowing the one shared by every system app.

• CPU boost hints now actually reach the scheduler. A long-standing bug in the MediaTek cpufreq driver made the frequency validator reject every valid frequency, so power hints were silently dropped.

• The LAUNCH hint now also raises the little cluster it is meant to boost, so app cold-start is measurably snappier.

• Removed the video-telephony HAL that nothing on this device provides, and turned ViWiFi off. Together these eliminated a log flood of roughly 9,500 lines per boot.

• MediaTek OMX codec libraries are properly registered in the blob list, so hardware video decoding no longer depends on leftovers.

• Camera tuning properties the HAL probes are labelled correctly, so a camera session no longer trips SELinux denials.

• The package no longer overwrites your recovery partition. Whatever recovery you installed stays where it is.

• Indian units get the stock Indian bootloader (lk_in.img), taken byte-for-byte from the official signed MIUI package.

• Firmware provenance verified against the official signed MIUI V12.5.8.0.RGGMIXM and V12.5.8.0.RGGINXM packages.

Known issues:

• VoWiFi and video calling (ViLTE / ViWiFi) are not available.

• Please report anything else you find, with a logcat if you can.
